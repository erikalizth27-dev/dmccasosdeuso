# Checklists de validación SDD

## Evidencia
- [ ] Historias, RF y reglas tienen fuente.
- [ ] Cifras y actores están sustentados.
- [ ] Contradicciones visibles.

## Specification
- [ ] Existen los 12 bloques.
- [ ] MVP y futuro separados.
- [ ] RF observables.
- [ ] RNF medibles o con pregunta.
- [ ] Criterios verificables.

## Datos
- [ ] Conceptual sin detalles físicos.
- [ ] Lógico con claves y cardinalidades.
- [ ] Físico trazado a consultas y RNF.
- [ ] Sin PII real.

## Código
- [ ] Historia, requisito y criterio existentes.
- [ ] Pruebas implementadas.
- [ ] Sin secretos.
- [ ] Lint, build y tests pasan.

## IA y agentes
- [ ] Propósito, datos, acciones y límites definidos.
- [ ] Human-in-the-loop.
- [ ] Evidencias, logs, umbrales y fallback.

## GitHub
- [ ] Rama correcta.
- [ ] Diff revisado.
- [ ] Commits descriptivos.
- [ ] PR con validaciones.
- [ ] No fusionar sin autorización.
